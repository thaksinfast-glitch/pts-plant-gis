# PTS Plant GIS — Google Sheets sync

ชุดนี้เตรียมเว็บแอปให้ทำงานเป็น Apps Script Web App ที่ผูกกับชีตปลายทาง

## ไฟล์ในชุด

- `Code.gs` — อ่าน/บันทึกข้อมูลกับ Google Sheets และให้บริการหน้าเว็บ
- `Index.html` — เว็บแอปพร้อมสถานะซิงก์

## ข้อมูลที่ส่ง

- รายการพรรณไม้: รหัส กลุ่ม โซน ชื่อ จำนวน ลักษณะวิสัย พิกัด แสงแดด ดิน ข้อสังเกต และวันเวลา
- รายชื่อกลุ่มสำรวจ
- รูปถ่าย JPEG ที่บีบอัดแล้ว โดยเก็บเป็นส่วนย่อยในแท็บ `รูปภาพพรรณไม้` และนำกลับมาแสดงในเว็บแอป
- ประวัติการเพิ่ม แก้ไข หรือลบรายการและกลุ่ม

PIN ครูจะไม่ส่งไปยังชีต รูปถ่ายจะถูกเก็บในชีตเดียวกัน จึงมีสิทธิ์การเข้าถึงเหมือนกับชีตปลายทาง

## ตำแหน่งในชีต

- แท็บแรกที่มีอยู่ (`ชีต1`) ใช้เก็บรายการพรรณไม้ปัจจุบัน
- แท็บ `กลุ่มสำรวจ` เก็บรายชื่อกลุ่ม
- แท็บ `รูปภาพพรรณไม้` เก็บรูป JPEG ที่แบ่งเป็นส่วนย่อยเพื่อไม่ให้เกินขนาดต่อเซลล์
- แท็บ `ประวัติการเปลี่ยนแปลง` เก็บประวัติรายการที่เพิ่ม แก้ไข หรือลบ

การเปลี่ยนแปลงข้อมูลปัจจุบันจะอัปเดตแท็บหลัก ส่วนประวัติจะบันทึกเป็นแถวเพิ่ม

## ติดตั้ง

1. เปิด Google Sheet เป้าหมาย แล้วเลือก **ส่วนขยาย → Apps Script**
2. วาง `Code.gs` แทนโค้ดในไฟล์ `Code.gs`
3. เพิ่มไฟล์ HTML ชื่อ `Index` แล้ววางเนื้อหาจาก `Index.html`
4. บันทึก เลือกฟังก์ชัน `getSnapshot` แล้วกด **เรียกใช้** เพื่ออนุญาต Apps Script ให้อ่านและแก้ไขชีต
5. เลือก **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้** แล้วแก้ไขเว็บแอป
6. ตั้ง **เรียกใช้ในฐานะ** เป็นบัญชีผู้ Deploy และตั้ง **ผู้ที่มีสิทธิ์เข้าถึง** เป็น **ทุกคนที่มีบัญชี Google**
7. เลือก **เวอร์ชันใหม่** แล้ว Deploy จากนั้นเปิด URL เว็บแอปที่ได้

เว็บแอปหลักทำงานใน Apps Script HTML Service เพื่อใช้ `google.script.run` ซิงก์ชีต หน้า GitHub Pages ทำหน้าที่เปิดเว็บแอปใน iframe โดยตั้ง URL ใน `pages-config.js` การเปิดไฟล์ `Index.html` แบบไฟล์ในเครื่องจะไม่ซิงก์

## หมายเหตุเรื่องสิทธิ์

ชีตปลายทางขณะตรวจสอบตั้งค่าแชร์เป็น “ทุกคนที่มีลิงก์แก้ไขได้” ควรตรวจสิทธิ์แชร์และจำกัดผู้ใช้ให้เหมาะกับโรงเรียนก่อนใช้งานจริง การตั้งค่าแชร์เดิมไม่ได้ถูกเปลี่ยน
